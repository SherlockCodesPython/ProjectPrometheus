# Project Prometheus

A decoupled Optimizely CMS 12 project using ASP.NET Core,
Content Delivery API and a React/Next.js frontend.

## Technology Stack

- Backend: Optimizely CMS 12 / .NET 8
- Frontend: Next.js / React
- Database: SQL Server LocalDB
- Version Control: Git / GitHub

## Project Structure

- Backend/ - Optimizely CMS application
- Frontend/ - React/Next.js application
